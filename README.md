# PropWise AI

**An Intelligent Real Estate Discovery, Price Prediction and Property Recommendation System Using AI and ML**
College mini-project · Hubballi–Dharwad, Karnataka

> **All listings in this project are synthetic demonstration data.** They are generated by
> `backend/scripts/generate_synthetic_data.py`, flagged `is_synthetic=true`, and are not real properties
> or market prices.

## Requirements

- Python 3.11 or newer (tested on 3.11 and 3.13)
- Node.js 20 or newer (tested on 22)
- Optional: Docker Desktop, for PostgreSQL. Without it the backend uses a local SQLite file.

## Run the backend (Windows PowerShell)

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1          # macOS/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt

copy ..\.env.example ..\.env           # then edit JWT_SECRET (optional for local dev)

alembic upgrade head                   # create tables
python scripts\seed_db.py              # load localities, amenities, demo accounts, 306 synthetic listings
uvicorn app.main:app --reload          # http://localhost:8000/docs
```

The trained price model is already saved in `ml/artifacts/price_model/`. To retrain it (and regenerate
`ml/reports/data_quality.md` and `ml/reports/model_evaluation.md` from the actual run):
```powershell
python scripts\train_price_model.py               # about 20 seconds; --no-tune skips the grid search
```
To re-run the recommendation evaluation (15 scenarios on a temporary copy of the demo data; rewrites
`ml/reports/recommender_evaluation.md`):
```powershell
python scripts\evaluate_recommender.py
```
The saved model only loads with the scikit-learn version pinned in `requirements.txt`; with another
version the API reports the model as unavailable (503) until you retrain.

To regenerate the synthetic CSV (same seed gives identical data):
```powershell
python scripts\generate_synthetic_data.py --n 300 --seed 42
python scripts\seed_db.py --reset
```

### Using PostgreSQL instead of SQLite
```powershell
docker compose up -d db
$env:DATABASE_URL = "postgresql+psycopg://propwise:propwise@localhost:5432/propwise"   # or put it in .env
cd backend; alembic upgrade head; python scripts\seed_db.py
```

### Demo accounts (created by the seed script)
Password: value of `SEED_DEMO_PASSWORD` (default `DemoPass123`).

| Role | Email |
|---|---|
| Admin | admin@demo.propwise.example |
| Seller | seller1@demo.propwise.example (also seller2, seller3) |
| Buyer | buyer@demo.propwise.example |

Real administrators are created with `python scripts\create_admin.py --email you@example.com`.

### The assistant (optional API key)
The Chat page works without any key, in the labelled **Basic search mode** (rule-based, same tools). To use the AI
assistant, add `ANTHROPIC_API_KEY=...` to `.env` and restart the backend; `GET /api/v1/health` then shows
`"llm_configured": true`. Calls are billed to that key. `LLM_MODEL`, `LLM_EFFORT` and `AI_RATE_LIMIT_PER_MINUTE`
are in `.env.example`.

## Run the frontend (second terminal)

```powershell
cd frontend
npm install
# optional: create .env.local with NEXT_PUBLIC_API_BASE_URL=... (default http://localhost:8000)
npm run dev                            # http://localhost:3000
```
The backend must be running and seeded first. Map tiles come from OpenStreetMap, so the map needs internet.

## Tests

```powershell
cd backend
pytest                                  # SQLite
$env:TEST_DATABASE_URL = "postgresql+psycopg://propwise:propwise@localhost:5432/propwise_test"
pytest                                  # same suite on PostgreSQL (database must exist)

cd ..\frontend
npm run typecheck; npm run lint; npm test   # TypeScript, ESLint, unit tests
npx playwright install chromium             # once
npm run e2e                                 # browser tests; needs backend (seeded) on :8000 and `npm run build; npm start` on :3000
```

## Quick API tour

```http
GET  /api/v1/health
GET  /api/v1/meta/enums
GET  /api/v1/localities?city=Dharwad
GET  /api/v1/properties?city=Dharwad&property_type=residential_plot&max_price=2500000&sort=price_asc
GET  /api/v1/properties/{id}
POST /api/v1/auth/login                 {"email": "...", "password": "..."}
POST /api/v1/properties                 (seller; stored as pending)
POST /api/v1/admin/properties/{id}/approve   (admin)
POST /api/v1/predictions/price          {"locality_id": 12, "property_type": "residential_plot", "area_value": "1200", "area_unit": "sqft"}
POST /api/v1/predictions/price          {"property_id": "..."}
GET  /api/v1/model-info
POST /api/v1/recommendations            {"max_budget": "2500000", "property_types": ["residential_plot"], "cities": ["Hubballi", "Dharwad"], "objective": "long_term_investment"}
GET  /api/v1/recommendations/config     (weights and scoring tables)
POST /api/v1/properties/compare         {"property_ids": ["...", "..."], "preferences": {...}}
GET  /api/v1/properties/{id}/similar
POST /api/v1/ai/chat                    {"message": "Residential plots in Dharwad under 25 lakh", "history": []}
```
Examples with responses: [docs/api.md](docs/api.md).
Full interactive documentation is at `http://localhost:8000/docs` once the server is running.

## Disclaimer

PropWise AI is an academic prototype for property research. It does not verify ownership or legal title,
does not provide legal or financial advice, and does not guarantee investment returns. Document statuses
reflect what a seller declared; always verify documents independently with the relevant authorities.
