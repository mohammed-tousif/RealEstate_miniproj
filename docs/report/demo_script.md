# Demo script: the 15-step scenario

About 10 minutes. The whole script is automated as `frontend/e2e/demo.spec.ts` and passed on the final build, so every
step below is known to work on the seeded demo data.

**Before you start**
- Local: start the backend (`uvicorn app.main:app`) and the frontend (`npm run build` then `npm start`).
- Render: open the site a minute early, because free services sleep after about 15 minutes idle.
- No API key is needed. Without one, the assistant runs in the labelled Basic search mode, which covers steps 12–15.
- Say once at the start: "Every listing here is synthetic demonstration data, generated by a documented formula."

| # | Do | Point out |
|---|---|---|
| 1 | Open the home page | Search box, category tiles, featured listings, the synthetic-data banner |
| 2 | Click **Advisor** in the navigation | One form for budget, type, location, objective and importance settings |
| 3 | Click **Try the demo** (₹25 lakh, residential plot, Hubballi or Dharwad, long-term investment) | Budget accepts lakh/crore; budget and type are strict, location is not |
| 4 | Read the ranked results | Each card has a 0–100 **suitability score**, which is not a probability of profit |
| 5 | Look at the factor bars and explanations on the first card | Five factors whose contributions add up to the score; data coverage; reasons, trade-offs and the price check |
| 6 | Click **Add to compare** on the first two cards | The count on **Compare** in the navigation |
| 7 | Open the first listing | Facts, land and legal status labelled "as stated by seller", map, amenities |
| 8 | Scroll to **Documents** | Each document shows Provided – unverified, Not provided, or Not applicable for this type; nothing is "verified" |
| 9 | Point to **Risk flags** (under the description, when a listing has any) and the **price estimate** card | Screening rules, not findings; the estimate has a range and says "not a valuation" |
| 10 | Scroll to **Similar listings** | KNN neighbours with what each has in common |
| 11 | Open **Compare** | Side-by-side table, ₹/sq ft warning across categories, "Match for your preferences" row with score and rank |
| 12 | Click **Ask the assistant why one ranks higher** | The Chat page opens and sends the question |
| 13 | Read the answer | "Ranking using the buyer's saved Advisor preferences", the point gap and the biggest factor differences, and links to both listings. The badge says AI assistant or Basic search mode |
| 14 | Click the first listing link, then **Ask whether its documents are verified** | The question is sent for that listing |
| 15 | Read the answer | "Stored document status for…", a statement that none is verified by PropWise, what to verify independently, and the official portal links |

**If something goes wrong**
- "The PropWise API is not reachable": the API is still waking up. Wait 30–60 seconds and reload.
- An empty Advisor result shows which requirement excluded the listings; relax the budget or type.
- With an API key set, the answer wording differs from run to run, but the facts come from the same tools.

**Optional extras, if time allows**
- Seller → admin workflow: sign in as `seller1@demo.propwise.example`, create a listing (it is stored as pending),
  then sign in as `admin@demo.propwise.example` and approve it. It now appears in search.
- **Estimate** page: price a 1200 sq ft plot in Saptapur and show the comparables.
- **Methodology** page: the model metrics against baselines and the recommendation weights.
